DoComposer

Docker Compose Builder

A friendly starting point if you're new to Docker: pick a few self-hosted services, get a working docker-compose.yml back, and skip the hour of copy-pasting and typo-hunting it usually takes to wire up more than one container by hand. Every port, volume and environment variable is editable before you download anything, and it warns you about port conflicts with containers already running on this host. No sign-up, nothing stored.
